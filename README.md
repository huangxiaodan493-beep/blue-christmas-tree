# Blue Gradient Christmas Tree

A blue gradient version of the particle Christmas tree at https://luna1188.github.io/Merry-Chrismas-trees./ .

The tree transitions from royal blue at the base to icy blue at the tip. The existing MediaPipe hand controller is preserved: enable the camera, open your hand to scatter the particles, close it to gather them, and move your hand to move the particles.

Requires HTTPS or localhost, camera permission, and network access to the original Three.js and MediaPipe CDNs. Camera recognition runs locally in the browser.

Publish the `main` branch root with GitHub Pages. No build step is required.
